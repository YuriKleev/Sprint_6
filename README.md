# Проект спринта 6: Яндекс.Самокат

## Описание проекта

**Яндекс.Самокат** — это сервис, позволяющий арендовать самокаты.

В рамках проекта необходимо покрыть UI-тестами следующий функционал сервиса:

### **Тестовые сценарии**

- Выпадающий список в разделе «Вопросы о важном».
Нужно проверить, что при нажатии на стрелочку, открывается соответствующий текст. На каждый вопрос необходимо написать отдельный тест.

- Заказ самоката.
Нужно проверить весь флоу позитивного сценария с двумя наборами данных. Также нужно проверить две точки входа в сценарий: кнопка «Заказать» вверху страницы и внизу.

### **Из чего состоит позитивный сценарий:**

- Нажать кнопку «Заказать». На странице две кнопки заказа.
- Заполнить форму заказа.
- Проверить, что появилось всплывающее окно с сообщением об успешном создании заказа.
- Проверить: если нажать на логотип «Самоката», попадёшь на главную страницу «Самоката».
- Проверить: если нажать на логотип Яндекса, в новом окне через редирект откроется главная страница Дзена.

UI-тесты описанного выше функционала выполнены с использованием **Selenium**, **Pytest** и **Allure**.

### Структура проекта

- `allure_results` - Allure-отчет
- `locators` - локаторы
- `page_objects` - пакет с методами тестирование
- `tests` - тесты
- `conftest.py` - фикстуры
- `data.py` - тестовые данные
- `url.py` - адреса страниц Самоката и Дзена

### Запуск автотестов

#### **Запуск автотестов с созданием отчета о тестировании в Allure**

 `pytest ./tests --alluredir=./allure-results`

#### **Формирование отчета в Allure**

 `allure serve ./allure-results`
